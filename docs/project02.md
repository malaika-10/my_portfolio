# Standalone Project 02

/project02/ is the unlisted Vanishing Stories presentation supplied in
portfolio vanishing stories.pdf. Its five pages are displayed in original order
and proportions, with 1537px responsive and 3074px HD slide graphics and extracted
screen-reader text where available. Every slide opens in a keyboard-dismissible
HD viewer. There are no links to this page from the homepage or project gallery.
The noindex/nofollow directive discourages indexing; it is not access control.
The existing Vanishing Stories detail page is unchanged.

Current display update: click-to-enlarge and viewer dialogs were removed from
all project detail pages at the user’s request. Animations and video controls
remain. See project03.md for the current interaction policy.
