# Vanishing Stories project graphics

The uploaded Vanishing stories.pdf contains one 1024.5 × 5760 point canvas.
The website presents all ten consecutive 576-point sections in the original order
as full-width graphics. Each section has a 1537 × 864 responsive WebP and a
3074 × 1728 HD WebP used on larger screens and in the enlarged viewer.

The homepage project card links to pages/vanishing-stories/. Text extracted from
each section is provided for screen readers. The page preserves the PDF artwork;
audio and video shown inside the PDF are still graphics until original media is
provided for those sections.

Sections: introduction; memory and target audience; big idea; why should we care;
research; role and interaction design; user flow; sketches and mood board;
app screens and prototypes; characters and audio.

The supplied Vanishing Stories cover.zip adds the original 1672 × 941 PNG as
an opening cover panel before the ten existing slides. It scales without cropping
and opens at its original resolution in the enlarged viewer.
